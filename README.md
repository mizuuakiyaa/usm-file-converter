# Usm-File-Converter
Converter that converts usm files into a mp4 format files 

# How to use

copy the repository

Install python 

in terminal:

pip install -r requirements.txt

python main.py / python3 main.py

# How to convert multiple files

.usm file location : path/to/your/usm/files/folder

output folder : /path/to/the/same/folder/as/before

name: (just click enter)
